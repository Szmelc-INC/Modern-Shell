# Modern Shell
> A consolidated project based on my other projects like Silver-ZSH and ZRC, and other shell features I have implemented across my system, all combined into one thing, that's modern. (modularity, good interactive TUI, nice readable formatted & colored output and more!)
> It relies on a wide range of dependencies like: zsh, fzf, zoxide, git, p10k, bat, highlight, and so on.
> It also "comes with" (is used alongside) software "not strictly shell, but still shell related" like nano, tmux, etc, and nice configs for those should also be made. (for example use my ~/.nanorc as a base for nano config, and .zshrc (AFTER CAREFULL EDITS AND FIXES) as base for default zsh config in this project.) Important things are my "zenfull" additions to it like colored output, syntax highlighting, interactive autocomplete, command suggestions, nice minimal prompt, and many more.
> On my system, there is also a folder called ~/.zsh/ in which are bunch of zshrc "addons", you can copy them over and make best of them into zsh addons properly. Fully revert to other snapshot or backup (list existing). and Remove old snapshot or backup (list to choose, and ask for confirmation). And as i mentioned it should auto run on every install. (the creation of new snapshot from current state before modifications).
